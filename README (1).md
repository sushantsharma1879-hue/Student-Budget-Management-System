
# Student Budget Management System

## Project Description

The Student Budget Management System is a Python-based application designed to help students manage their daily expenses and monthly budgets.

## Features

- Add expenses
- View expenses
- Search expenses
- Update expenses
- Delete expenses
- Set category-wise budgets
- View budget status
- Generate expense reports
- SQLite database storage
- Input validation

## Technologies Used

- Python
- SQLite
- Google Colab

## Modules

- main.py
- database.py
- expense.py
- budget.py
- reports.py
- validation.py
- utils.py
- test_project.py
